# 🦁 Wildlife Population Intelligence System

An AI-powered Wildlife Population Intelligence System for monitoring biodiversity, identifying wildlife species, estimating animal populations, and supporting conservation efforts using computer vision, bioacoustic analysis, and machine learning.

## 📌 Features

* User Authentication & Role-Based Access
* Wildlife Survey & Monitoring Management
* Camera Trap Image Management
* Audio Sensor Management
* Wildlife Species Identification
* Population Estimation
* Biodiversity Analysis
* Habitat Health Monitoring
* Conservation Recommendations
* Interactive Dashboards
* Reports & Analytics

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/your-username/wildlife-population-intelligence-system.git
cd wildlife-population-intelligence-system
```

### Backend

```bash
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

## 🐳 Docker

```bash
docker compose up --build
```
